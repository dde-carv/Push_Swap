## Overview

**Push_Swap** is a program that sorts data on a stack, with the lowest possible number of instructions, using only a limited set of stack operations. The goal is to sort an input sequence of integers (provided via command line) by manipulating two stacks (A and B) through operations like push, swap, rotate, and reverse rotate.

## Features

- Written entirely in C
- Custom Makefile for easy compilation
- Modular structure (`inc`, `src`, `libft`)
- Implements classic stack sorting algorithms
- Designed for efficiency and minimal instruction count
- No external dependencies

## Installation

Clone the repository:
```bash
git clone https://github.com/dde-carv/Push_Swap.git
cd Push_Swap
```

Build the project:
```bash
make all
```

Or for [bonus part](#bonus-usage):
```bash
make bonus
```

This will generate the `push_swap` executable.

## Usage

Run the program by passing a sequence of integers as arguments:
```bash
./push_swap 3 2 1 6 5 4
```
The output will be a list of operations that will sort the stack.

### Example

```bash
./push_swap 2 1 3
sa
```
This indicates a single swap (`sa`) will sort the stack.

## Bonus Usage

The bonus part of the project provides a `checker` program, which is used to validate the sequence of operations produced by `push_swap`. This adds additional robustness and allows automated verification of your sorting logic.

### 1. Interactive Usage with `checker`

You can manually enter a sequence of operations for the stack, and `checker` will verify if the final result is correctly sorted. After entering your operations, signal the end of input with CTRL+D:

```bash
./checker 2 1 3
sa
OK
```

- If the stack is sorted after applying the operations, `checker` outputs `OK`.
- If the stack remains unsorted, `checker` outputs `KO`.

### 2. Automated Validation with Piping

You can also automate the verification process by piping the output of `push_swap` directly into `checker`. This is useful for testing your sorting algorithm end-to-end:

```bash
./push_swap 0 9 1 8 2 7 3 6 4 5 | ./checker 0 9 1 8 2 7 3 6 4 5
```

If the operations generated by `push_swap` result in a sorted stack, `checker` will output `OK`:

```bash
./push_swap 0 9 1 8 2 7 3 6 4 5 | ./checker 0 9 1 8 2 7 3 6 4 5
OK
```

## How it Works

The program manipulates two stacks (A and B) using the following allowed operations:

- `sa`, `sb`, `ss`: swap the top two elements of stack A, B, or both
- `pa`, `pb`: push the top element between stacks
- `ra`, `rb`, `rr`: rotate stack A, B, or both upwards
- `rra`, `rrb`, `rrr`: rotate stack A, B, or both downwards

The challenge is to sort any given input with as few operations as possible. The algorithm's efficiency is a key evaluation metric.
